# DLNA SERVER v1.5

**Автор / Maintainer:** artsailer  
**Лицензия / License:** GPL-3.0-or-later  
**Платформы / Platforms:** Kubuntu, Ubuntu, Linux Mint, Debian (X11 & Wayland)

## О программе
Лёгкий и быстрый локальный DLNA/UPnP медиасервер с графическим интерфейсом на **PyQt6** и движком **MiniDLNA**. Позволяет в один клик транслировать фильмы, музыку и фотографии на Smart TV, смартфоны и планшеты в вашей домашней Wi-Fi/LAN сети.

## Ключевые возможности
* **Безопасность и приватность:** работает строго в локальной сети без открытых веб-интерфейсов управления.
* **Автоматическая настройка:** сам определяет активный сетевой интерфейс и IP-адрес, генерирует уникальный `UUID` устройства.
* **Умное управление системой:** встроенные переключатели **«Анти-сон»** (`systemd-inhibit`), **«Миниатюры»** и **«Автозапуск»** в системный трей.
* **Чистая интеграция:** не конфликтует со стандартной службой `minidlna.service` и корректно восстанавливает её при удалении пакета.
* **Двуязычный интерфейс:** мгновенное переключение между русским (`RU`) и английским (`EN`) языками.

## Установка
Установите пакет двойным кликом через центр приложений (Discover / GDebi) или через терминал:
```bash
sudo apt install ./dlna-server-1.5-all.deb
```
